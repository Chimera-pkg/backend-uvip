UVIP — Urban Visual Perception API

Dokumentasi lengkap REST API untuk survei persepsi visual perkotaan: manajemen koridor, misi survei, foto street-level, hasil segmentasi & prediksi persepsi, simulasi skenario, hingga rekomendasi kebijakan.

Base URL
http://127.0.0.1:8000
Autentikasi
JWT Bearer Token
Format
JSON · multipart (upload)
Swagger / ReDoc
/docs · /redoc
🔑 Sertakan header Authorization: Bearer <access_token> pada semua endpoint kecuali POST /auth/register & POST /auth/login.
